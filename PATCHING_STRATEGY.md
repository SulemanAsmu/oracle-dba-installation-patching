# 📋 Oracle Patching Strategy

## 🔄 Oracle Patch Types

| Patch Type | Description                        | Frequency     |
|-----------|-------------------------------------|---------------|
| RU        | Release Update (quarterly)          | Every quarter |
| RUR       | Release Update Revision             | As needed     |
| One-off   | Fix for specific bug                | As needed     |
| PSU       | Patch Set Update (older versions)   | Old style     |
| CPU       | Critical Patch Update (security)    | Quarterly     |
