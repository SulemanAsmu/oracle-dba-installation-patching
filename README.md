# 🖥️ Oracle DBA Installation & Patching on AIX

## 📋 Description
This repository contains professional scripts for installing
and patching Oracle Grid Infrastructure and Oracle Database
on IBM AIX operating system.

## 🛠️ Environment Details

| Component              | Details                          |
|-----------------------|----------------------------------|
| Operating System       | IBM AIX 7.2 / 7.3               |
| Oracle Version         | Oracle 19c (19.3.0.0)           |
| Grid Infrastructure    | Oracle GI 19c                   |
| Patch Type             | Release Update (RU)             |
| Latest RU Applied      | 19.21.0.0 (Jan 2024)            |
| OPatch Version         | 12.2.0.1.41                     |
| Cluster Type           | Oracle RAC / Single Instance    |
| ASM Storage            | Oracle ASM                      |
| Server                 | IBM Power System                |

## 📁 Repository Structure

| Folder                 | Description                              |
|-----------------------|------------------------------------------|
| aix-os-preparation     | AIX OS setup and requirements            |
| grid-infrastructure    | Oracle GI 19c installation               |
| oracle-database        | Oracle DB 19c installation               |
| patching               | OPatch and DataPatch procedures          |
| response-files         | Silent install response files            |
